# 小红书分页卡片编辑器设计

## 背景

当前小红书页面把正文编辑器和手机预览分成两个区域。用户编辑的是 HTML 源码或独立表单，预览看到的是另一套结果，编辑与发布图片之间存在明显割裂。小红书的实际发布对象是可左右滑动的多张图片，因此 InkHub 需要把“页面卡片”作为主要编辑对象。

## 目标

- 将小红书正文改为按模板尺寸分页的卡片画布。
- 每张卡片可以独立编辑，编辑结果与最终导出图片一致。
- 支持左右滑动浏览卡片，并显示当前页码和总页数。
- 图片在卡片内居中并限制最大宽度。
- 代码块作为不可拆分内容块，当前页空间不足时整体移动到下一页。
- 表格在宽度和高度都能容纳时保留；否则转换为可读的结构化普通文本。
- 保留模板选择，但暂不增加独立的模板缩略图预览区。
- 话题、来源说明、评论区文案作为发布设置，不占用正文卡片空间。

## 非目标

- 第一版不实现类似专业设计软件的自由拖拽、旋转、图层和绝对定位。
- 第一版不支持表格在卡片之间拆分。
- 第一版不把小红书图片直接发布到平台，仍由用户导出后手动发布。
- 第一版不要求兼容旧草稿的逐像素排版；旧草稿可以通过重新提取或重新分页生成新版本。

## 方案选择

### 方案 A：整段 HTML 自动滚动分页

实现成本最低，但页面边界由浏览器自然布局决定，用户无法明确控制某个段落属于哪一张卡片；编辑后分页结果也容易跳动。

### 方案 B：内容块 + 页面卡片模型（采用）

将正文拆为段落、标题、图片、代码、表格等内容块，再按模板尺寸分配到多个页面。页面是稳定的编辑边界，代码和图片等不可拆分块可以整体移动，符合小红书发布方式，也便于后续保存页面级修改。

### 方案 C：Canvas 图片编辑器

视觉自由度最高，但文本编辑、可访问性、撤销和内容保存成本很高，不适合 InkHub 当前以文章转化为核心的工作流。

## 交互设计

### 页面布局

- 顶部：返回、撤销、重做、标题/段落、列表、引用、代码、图片等常用工具。
- 中央：横向卡片画布，每张卡片按选定模板渲染，支持左右滚动。
- 右侧：模板选择和简要模板参数，不显示第二套独立预览。
- 底部：字数、当前页/总页数、保存状态、导出图片集。
- 发布设置：话题文本（如 `#AI编程 #效率工具`）、来源说明和评论文案放在折叠或独立设置区域。

### 编辑行为

- 卡片内直接所见即所得编辑，用户看到的不是 HTML 标签。
- 每张卡片有明确的编辑边界；在卡片内修改不会直接覆盖其他卡片。
- 普通段落可以在当前页继续编辑和拆分。
- 代码块、图片和表格视为整体块，空间不足时移动到下一页。
- 卡片内容为空时允许保留，用户可以删除空卡片或继续输入。
- 分页重新计算只影响当前卡片及其后的卡片，并保留用户已经编辑的内容块。

## 分页规则

1. 以模板的内容宽度、高度、内边距和字体参数建立测量容器。
2. 按内容块顺序测量高度，普通段落允许在行边界拆分。
3. 代码块不可拆分；放不下时移动到下一页。
4. 表格先测量宽度和高度：完整容纳则保留表格；宽度或高度超限则转换为“字段：值”或按行连接的普通文本块。
5. 图片保持比例，最大宽度为卡片内容宽度并水平居中；单张图片高度超过页面可用高度时按模板上限缩放。
6. 每次分页产生稳定的块 ID，避免用户编辑一个卡片后所有后续卡片都被视为全新内容。

## 数据与兼容

内部草稿建议保存为页面和内容块结构，至少包含：

- `template_id`、`template_version`
- `pages[]`：页面 ID、块顺序、页面级样式
- `blocks[]`：块 ID、类型、内容、来源块 ID、是否可拆分
- 话题、来源说明、评论文案

当前仅保存 `body_html` 的旧草稿继续可读取，但打开后先转换为块并分页；用户保存或重新 AI 提取时写入新版本格式。旧 API 字段可以在过渡期保留，前端不再直接编辑它。

## 错误与边界

- 模板测量失败时显示明确错误，并保留最近一次可用分页结果。
- 单个代码块或图片超过整页高度时按模板最大尺寸缩放，并提示用户。
- 表格转换失败时保留原内容并阻止导出，避免静默丢失信息。
- AI 生成失败不覆盖当前草稿，用户可以重试或继续编辑当前版本。
- 保存和导出使用同一份页面模型，导出的图片页数必须与预览一致。

## 验收标准

- 页面中不存在 HTML 源码编辑框。
- 用户可以左右浏览所有卡片，并在任意卡片中直接编辑。
- 代码块不会被截断；空间不足时完整移动到下一页。
- 可容纳的表格保持表格样式，超宽或超高表格转为可读文本。
- 图片在每张卡片内居中且不溢出。
- 保存后重新打开，页面顺序、模板和正文内容保持一致。
- 导出图片与预览逐页一致，话题可直接复制为带 `#` 的单行文本。
