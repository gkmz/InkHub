# 小红书中文悦读模板设计

## 目标

小红书发布页只保留一个默认模板“中文悦读”，面向中文技术长文提供护眼、清晰、有稳定阅读节奏的预览和导出体验。

## 视觉方向

- 背景使用冷灰绿纸张色 `#f3f6f1`，避免纯白长时间阅读的刺眼感。
- 主文字使用松烟墨色 `#1f2d29`，标题使用深墨绿 `#183f35`。
- 朱砂色 `#9a5642` 只用于引用、表格卡片和少量结构强调。
- 正文优先使用 `Songti SC`、`STSong` 等中文宋体；标题、标签和代码使用系统黑体或等宽字体。
- 正文行高保持 `1.85`，段落间距明确，标题和正文形成稳定的中文阅读节奏。

## 结构规则

- 模板注册表只暴露一个模板，保留 `mobile-clean` ID 兼容旧草稿和历史渲染记录。
- 卡片维持 `375 × 667`，导出维持 `750 × 1334`。
- 表格在窄屏中按数据行转换为字段卡片，并使用朱砂左边线区分结构。
- 图片独占一行并带克制阴影；代码块使用浅灰绿底色；引用使用墨绿竖线和朱砂小标题感。
- 预览和导出使用同一组颜色、字体、间距和内容缩放规则。

## 验收标准

- 模板选择器只显示“中文悦读”。
- 预览和导出不再出现其他模板样式。
- 中文正文、标题、引用、表格、图片、代码和 Mermaid 均清晰可读。
- 实际 ZIP 导出包含全部分页 PNG，页面无底部或横向裁切。
