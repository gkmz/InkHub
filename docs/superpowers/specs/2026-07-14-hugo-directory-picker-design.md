# Hugo 目录选择设计

## 目标

首次引导的 Hugo 根目录支持系统原生目录选择，同时保留手工输入和“暂不配置博客”。

## 设计

前端复用现有路径输入控件和文件夹图标。`pickDirectory` 接收 `vault` 或 `hugo` 用途并发送 JSON；后端只接受这两个固定值，分别使用“选择 Obsidian Vault”和“选择 Hugo 项目根目录”作为原生对话框标题。选择失败显示在对应字段下，不影响手工输入。

## 验收

- Hugo 根目录右侧存在可访问名称为“选择 Hugo 目录”的按钮。
- 点击后请求包含 `purpose: "hugo"`，成功时填写返回路径。
- 后端拒绝未知用途，且目录选择接口继续执行同源校验。
- Vault 选择继续使用 `purpose: "vault"`，既有流程不回归。
