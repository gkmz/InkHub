# Tokyo Night 代码高亮设计

## 背景

当前统一 Markdown 渲染器使用 `github` 主题生成行内颜色，导致审核、微信和小红书虽然可以分别设置代码块容器，却无法真正控制语法 token 配色。旧版 InkHub 在 `old/markdown/chroma_style.go` 中注册了完整的 `tokyonight-night` 主题，代码块背景为 `#1a1b26`，正文为 `#c0caf5`。

本次恢复旧版 Tokyo Night 视觉，并让最终样式归属符合产品边界：审核页固定使用该主题，微信和小红书由各自模板控制。

## 目标

- 审核页、微信预览与复制结果、小红书预览与导出图片均使用旧版完整 Tokyo Night 代码高亮。
- 精确复用旧版 token 色值，不使用相似主题替代。
- 围栏代码块使用 Tokyo Night，行内代码继续使用各页面现有的浅色强调样式。
- 微信复制后的 HTML 保留 token 颜色，小红书导出结果与页面预览一致。
- Mermaid 继续渲染为图表，不作为普通代码块显示。

## 非目标

- 不增加代码高亮主题选择器。
- 不猜测未声明语言的代码块语言。
- 不改变行内代码的现有交互和排版。
- 不新增自动化测试代码。

## 方案选择

采用“Markdown 输出语义类名，消费方负责主题样式”的方案。统一渲染器只标识 Chroma token，不再通过 `github` 主题写入固定的行内颜色。

未采用统一输出 Tokyo Night 行内样式，因为这会使微信和小红书模板无法控制代码主题。也不为三个渠道建立独立 Markdown 渲染器，避免重复解析逻辑和渠道间 HTML 结构漂移。

## 架构设计

### 统一 Markdown 输出

`internal/content/markdown` 使用 Chroma class 模式生成稳定的语义类名。语言已声明时按对应 lexer 高亮；未声明或无法识别时输出普通代码文本。渲染器不承担最终 token 颜色。

### 审核页面

审核页面在通用前端样式中固定声明 Tokyo Night 容器和 token 规则。样式只作用于围栏代码块生成的 Chroma 容器，不能覆盖 `:not(pre) > code` 的行内代码规则。

### 微信模板

内置墨绿模板包含完整 Tokyo Night token 规则。微信渲染器的 CSS 匹配能力扩展为支持模板范围内的 class 选择器，例如 `.inkhub-root .k` 和 `.inkhub-root .s`。

发布准备流程先将模板规则应用到 Chroma 节点，再把计算出的颜色转换为节点行内样式。安全清理阶段可以移除 class，但必须保留已经生成的 `style`，确保浏览器自动复制和手工复制弹窗得到同样的高亮 HTML。

### 小红书模板

唯一的“中文悦读”模板承载 Tokyo Night 代码主题。模板规则同时用于：

- 卡片编辑预览；
- 隐藏 DOM 的分页高度测量；
- SVG 快照与 PNG 导出。

三处必须使用相同的容器尺寸、字体、换行和 token 色值，避免预览、分页和导出产生差异。普通代码块允许长行换行，不能横向撑破固定宽度卡片。

## 主题色值

主题以旧版 `tokyonight-night` 为唯一基准，包括：

- 背景 `#1a1b26`，正文 `#c0caf5`，空白 `#3b4261`；
- 注释 `#565f89`，关键字 `#bb9af7`，声明和函数 `#7aa2f7`；
- 字符串 `#9ece6a`，数字与常量 `#ff9e64`；
- 运算符 `#89ddff`，类型 `#2ac3de`，属性 `#73daca`；
- 错误和变量 `#f7768e`，日期及插值 `#e0af68`。

其余 token 按旧文件逐项迁移，不对颜色进行简化。

## 兼容与错误处理

- 现有已保存 HTML 中若仍带行内 `github` 色值，新一次从原文渲染或重新生成分页时应得到 class 模式 HTML；不执行数据库迁移。
- 微信模板校验仍拒绝越界选择器、危险属性和危险 CSS 值；只增加模板根节点内简单 class 选择器的支持。
- 不认识的语言回退为普通文本，代码内容必须完整显示。
- Mermaid 的识别和图片替换优先级保持不变。

## 验证

不新增测试文件。实现完成后执行：

- Go 格式化、现有相关测试或编译检查；
- 前端 TypeScript 检查和生产构建；
- 启动本地应用，从页面检查审核、微信、小红书三处；
- 使用至少一段包含注释、关键字、字符串、数字和函数名的代码核对 token 配色；
- 检查微信复制内容和手工复制弹窗；
- 导出小红书图片并核对预览与 PNG 的代码颜色、换行和边界。

## 验收标准

- 三类页面的围栏代码块均呈现旧版 Tokyo Night 深色高亮。
- 行内代码保持浅色且字号继承所在正文或标题。
- 微信复制到富文本目标后仍保留语法颜色。
- 小红书预览、分页测量和导出图片没有样式差异或内容溢出。
- 表格、图片、引用链接和 Mermaid 等现有能力无回归。
